## Step Tracker

  A PHP web application for logging and tracking daily steps. Built as my first full-stack project using an MVC
  architecture with team and individual leaderboards.

  ---

  ## Features

  - User authentication with session management and IP blocking
  - Log daily step counts
  - Team leaderboard showing cumulative steps per team
  - Individual leaderboard ranked by total steps
  - Account management — update nickname and password
  - Login attempt tracking with rate limiting and IP blocking

  ---

  ## Tech Stack

  - **Backend:** PHP
  - **Database:** MySQL
